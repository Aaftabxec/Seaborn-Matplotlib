# 📊 Data Visualization with Matplotlib & Seaborn

## 📌 Project Overview

This project focuses on learning and implementing data visualization techniques using Python libraries, primarily Matplotlib and Seaborn.

The notebook uses the built-in Iris dataset to explore different visualization methods and understand relationships, distributions, patterns and variations within data.

The objective is to develop practical knowledge of data visualization and understand how graphical representations help in Exploratory Data Analysis (EDA).

## 🎯 Project Objectives

- Understand the fundamentals of data visualization.
- Learn to use Matplotlib and Seaborn.
- Explore datasets using Pandas.
- Visualize numerical and categorical data.
- Identify data distributions and potential outliers.
- Understand relationships between different variables.
- Analyze correlations using heatmaps.

## 📂 Dataset Used

**Iris Dataset**

The Iris dataset is a built-in dataset available in Seaborn. It contains measurements of three species of Iris flowers:

- Setosa
- Versicolor
- Virginica

### Dataset Features

| Feature | Description |
|---|---|
| Sepal Length | Length of the sepal |
| Sepal Width | Width of the sepal |
| Petal Length | Length of the petal |
| Petal Width | Width of the petal |
| Species | Type of Iris flower |

## ⚙️ Installation and Setup

### Prerequisites
- Python 3.x
- Jupyter Notebook

### Step 1: Clone the Repository

```bash

```

### Step 2: Navigate to the Project Folder

```bash
cd Matplotlib
```


### Step 4: Launch Jupyter Notebook


Open the notebook and execute the cells to explore the visualization techniques.
